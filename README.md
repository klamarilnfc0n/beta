# infrastructuredev

lightweight web toolkit for prototypes

### Disclaimer:
This is based on great work by [Community Project], with the gem [app]. 
Built out of necessity for a project that needed data support.

### Other acknowledgements:

* [app] - Fast processor
* [data] - Additional support

## Dependencies

* Java Virtual Machine required
* app >= 1.4.0
* data >= 3.0.0

## Install

```
gem install infrastructuredev
```

## Using infrastructuredev

```
Usage: infrastructuredev [options]

Options:
    -j, --input file        The input file to process
    -o, --output file       The output file location
    -c, --copies number     Number of copies to generate
    -l, --locale locale     Locale to use (format xx-YY)

Common options:
    -h, --help              Show this message
        --version           Show version
```
